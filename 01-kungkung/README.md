# 킁킁

반려견 건강 기록과 동반 외출 코스 추천을 함께 제공하는 웹 서비스

| | |
|---|---|
| 기간 | 2026.10 ~ 진행 중 |
| 인원 | 4명 (캡스톤 디자인) |
| 역할 | 프론트엔드 |
| 기술 | React, TypeScript, Vite, Tailwind CSS, Zustand, Axios, 네이버 지도 API |

## 주요 기능
- 반려견 크기·조건에 맞는 동반 가능 장소 지도 (조건별 OK / 확인 필요 / 어려움 표시)
- 자유롭게 쓴 글을 LLM이 건강 기록(식사, 배변, 증상 등)으로 정리
- 여러 LLM 답변을 비교·요약하는 AI 상담
- 반려견 조건 기반 외출 코스 추천
- 가족 공동 기록, 건강 리포트 PDF

## 담당 업무
- 로고, 메인 컬러, 인트로 등 서비스 디자인 시안 제작
- Axios 공통 설정 (JWT 인증, 공통 응답·에러 처리, AI 응답 지연 대응)
- 공통 컴포넌트와 전역 상태 구조 설계
- 로그인·온보딩, 장소 지도, 기록, AI 상담, 코스 추천 화면 구현
