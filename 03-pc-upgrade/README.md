실습 PC를 분해·재조립하고, 머신러닝용 업그레이드 방안을 예산별로 설계한 팀 프로젝트

| | |
|---|---|

## 담당 업무
- 역할 분배와 일정 관리, 보고서 취합
- 분해·조립 과정 정리, 현재 PC 성능 분석, 서론·결론 작성

## 내용
- 재조립 후 부팅이 안 되는 문제를 RAM → SSD → CPU 순으로 점검해 해결
- 머신러닝에 필요한 사양과 비교해 GPU·파워가 부족한 것을 확인
- 예산 5단계로 업그레이드안을 비교하고 최종 구성 제안
