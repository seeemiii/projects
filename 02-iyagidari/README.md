# 이야기다리

발달장애 아동을 위한 맞춤 소셜 스토리를 AI로 만들고, 작성 기준을 지켰는지 자동으로 검증하는 서비스

| | |
|---|---|
| 기간 | 2026.10 ~ 2026.11 |
| 인원 | 개인 |
| 구분 | AI API 활용 아이디어 경진대회 출품 |
| 기술 | Python, Streamlit, Gemini API, Claude API |

## 핵심 아이디어
글을 쓰는 AI와 검사하는 AI를 분리했습니다.
검사 AI가 문장 유형을 분류하면 코드가 기준(문장 비율, 구조 등)을 판정하고, 통과하지 못하면 다시 쓰게 합니다(최대 3회).
최종 공개는 교사가 확인한 뒤에만 가능합니다.

## 구현
- 아동 정보·상황 입력 → 이야기 생성 → 기준 검증 → 재작성 → 교사 검토·공개
- 여러 상황을 한 번에 돌리는 실험 도구 (결과 기록, 중단 후 이어서 실행)

## 결과
| 항목 | 결과 |
|---|---|
| 테스트 상황 | 6개 |
| 3회 안 통과율 | 100% |
| 1회 만에 통과율 | 67% |
| 1편당 소요 시간 | 평균 48.9초 |

## 트러블슈팅
- 모델 응답 지연 → 모델별 응답 시간을 직접 측정해 빠른 모델로 교체
- API 요청 한도 초과 → 대기 후 재시도 로직 추가
- 실험 중 결과 유실 → 상황마다 바로 저장하고 이어서 실행하도록 수정
